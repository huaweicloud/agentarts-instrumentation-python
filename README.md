# agentarts-instrumentation-python

[![License](https://badgen.net/static/License/Apache-2.0/blue)](LICENSE)



华为云agentarts-instrumentation-python是一个专为华为云AgentArts平台设计的面向开发者的Python发工具包。该SDK支持使用Langchain/Langgraph、OpengJiuwen、Hermes等开源高码Agent框架开发的智能体，实现一键将Trace数据上报AgentArts可观测平台，帮助用户快速实现智能体的观测分析、评估与优化。



## 安装

```bash

pip install agentarts-instrumentation-python

```
